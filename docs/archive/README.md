# 归档

这里放**功能已经完成的文档**，不是废纸篓。判据只有一条：

> **计划类文档在它规划的工作做完之后就归档；证据类文档永不归档。**

计划书的作用是"决定接下来怎么做"，一旦做完，它对现状的描述必然过时，
留在 `docs/` 顶层只会被当成现状读 —— 本仓吃过这个亏（见
[#78](../stage4-findings.md#78) / CLAUDE.md M16："发版说明写了不等于文档更新了"）。
而**案卷（findings / results）记的是当时测到了什么**，那是永久有效的证据，
即使结论后来被推翻也要留着，并在原地标注推翻它的条目。
