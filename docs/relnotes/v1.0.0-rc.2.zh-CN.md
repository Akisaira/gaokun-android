华为 **MateBook E Go**（骁龙 8cx Gen 3 / SC8280XP）上的 Android 16（crDroid），跑在**主线 Linux 内核**上，Adreno 690 有硬件 Vulkan。

**1.0 的第二个候选版。** 和 1.0.0-rc.1 相比：**M-Pencil 手写笔有驱动了**；触摸驱动有了**手掌识别**；**待机时 Wi-Fi 保持连接**，
固件崩溃后也能自己恢复；**待机更省电**（音频 DSP 现在能睡了）；给音游的**低延迟音频通路**；电源键旁边的 USB-C 口**恢复 USB 3**，
并修了几处角色切换问题；《英雄联盟手游》**打开不再立刻退出**。为了通过一些游戏的环境检测，内核现在**对外报告一个伪装的版本号**（见下文）。

## 这个候选版是怎么测的

2026-10-18 装在开发者的机器上（在上一个开发构建上升级，不是全新安装）。在**这一版本身**上测过的：发版验收 A 档 **47 项通过、0 项失败**、
1 项提醒（即已知的两类 SELinux 拒绝）；待机时 Wi-Fi 保持连接（开着 WoWLAN，3 次真实的挂起 / 唤醒，没有断线重连，没有报错）；
音频 DSP 现在会睡；内核伪装版本号及其副作用（见下文）；SELinux enforcing 下崩溃记录能正常写出。
还没在这一版上做的：用真的笔和手测手写笔与手掌识别；接外设测 USB-C 角色切换；WoWLAN 过夜；音游延迟测量；
真机上用安装器全新安装；与 Windows 双系统；0.7.x → 1.0 的升级。

## 手写笔与触摸

* **华为 M-Pencil 能用了**（压感、悬停、倾斜、侧面双击）：笔由触摸屏的第二颗控制芯片感应，这颗芯片现在有了驱动，另有一个小服务负责笔的充电 / 配对控制器。
  贡献者在自己的机器上用同样的代码测过；**我们还没拿真笔在这一版上测**。
* **手掌识别**：手掌或手的侧面放在屏幕上会被认出来，事后才发现属于手掌的那些触点会被撤回（App 收到的是*取消*，不是点击）。
  游戏触摸预设会关掉它，免得屏幕边缘的拇指被吞掉。贡献者测过，这一版上还没测。

## Wi-Fi 与待机

* **待机时 Wi-Fi 保持连接。** 以前每次待机都会断开 Wi-Fi、给芯片断电，每次醒来再重新连。消息仍然要等系统自己醒来才收得到 ——
  网络上来的数据还不能把机器叫醒（见已知问题）。在这一版上测过。
* 待机中如果断线，现在会**在息屏状态下自己连回来**；以前要等到亮屏。Wi-Fi 固件偶尔拒绝进入待机模式时，这次待机会稍后重试，不再断开连接。
  贡献者测过，这一版上还没测。
* **Wi-Fi 固件崩溃后能自己恢复**，包括在待机中崩溃的情况。以前崩溃可能让内核挂掉，或者到下次冷启动前 Wi-Fi 都起不来。贡献者用注入崩溃的方法测过。
* **音频 DSP 能睡了**，待机更省电：音频编解码器不再一直把它吵醒。在这一版上测过（DSP 的睡眠计数在涨，以前一直是 0）。
  这一版具体省了多少电还没量；贡献者量到的是，加上这项和 Wi-Fi 那几项改动以后，待机功率约 0.63 W，之前约 0.74 W。

## 音频

* **给游戏的低延迟输出**：请求低延迟的游戏现在走 Android 的快速混音通路，在开发构建上量到的输出延迟从约 317 ms 降到约 110 ms。这一版上没重新量。

## USB-C

* **电源键旁边的口恢复 USB 3 速度**（之前被限制在 USB 2）；它需要的一路电源现在保持常开 —— 这修好了"作为 USB 设备时进待机就整板复位"。
* 这个口的角色（主机或设备）现在按插入的东西决定，由一个正式的 USB 端口服务负责，不再靠脚本；待机中插拔会唤醒机器。
* USB-C 控制器驱动（UCSI）的几处修复，正在投给上游。
* 以上都是贡献者测的；**这一版上还没接外设测**。

## 游戏

* **《英雄联盟手游》打开不再立刻退出**：能进到用户协议页面，能不能打完一局还没测。这个游戏默认 64 位进程拿不到 2^39 以上的内存地址；
  内核现在默认只分配这以下的地址。
* **内核对外报告一个伪装的版本号** `6.6.30-android15-8-…`，因为有些游戏不肯在自称 7.x 的内核上运行。实际跑的是 Linux 7.2.9。
  这是有意的，副作用是：bug 报告和崩溃记录里显示的是伪装版本；KernelSU 管理器会把内核认成 `android15-6.6` —— **不要用管理器里的"安装" / LKM 修补**。
  已在这一版上核对：系统其他部分的行为没有因此改变。
* 补上了 Android 策略本来就要求的 netlink 隐私边界：普通 App 读不到 Wi-Fi 网卡的硬件 MAC 地址和局域网里其他设备的列表；
  system_server 不再需要可写可执行的内存。大型 OpenGL ES 游戏两次运行之间能留住更多的着色器缓存。

## 其他

* SELinux：相机预览到一半不再报错（issue #23）；App 崩溃又能留下崩溃记录了。
* 安装器（`0.2.0-rc.2`）：安装器 / 救援系统的文本控制台不再被 USB-C 驱动的消息刷屏；后台任务不再误报丢失。

## 已知问题

* **不要随手点设置里的"清除所有数据（恢复出厂设置）"，也不要指望它。** 同 rc.1：启动入口应当会执行它，但真正的擦除这一步没测过。
  请用图形安装器的*重新安装 Android*。
* **待机时消息推送会晚到**：通常晚一两分钟，偶尔三分钟左右。Wi-Fi 是连着的，但网络上来的数据还叫不醒机器。
* **KernelSU 管理器会认错内核**（见*游戏*）：不要用它的"安装" / LKM 修补。
* 手工分区、EFI 分区名字不标准的硬盘上，**系统更新和切换槽位会失败** —— 一行命令的修法见 rc.1 的说明。
* 手工删过 Windows 的机器可能还会显示"重启到 Windows"；安装说明里写了怎么去掉。
